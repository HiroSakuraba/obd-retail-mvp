Real Adapter BLE Scan

Pair this phone or laptop with a real commodity BLE OBD-II adapter (Veepeak-class) and run the product's read-only scan sequence. There is no free-form command input on this page — only the allowlisted scan commands can ever be sent, matching the app's read-only stance.

Before you start

  1. Plug the adapter into the car's OBD-II port (under the dash).
  2. Turn the ignition on — engine running is best for live data.
  3. Enable Bluetooth on this phone/laptop. You do not need to pair in system settings; the page connects directly.
  4. Tap Scan for adapter below and pick your adapter.
